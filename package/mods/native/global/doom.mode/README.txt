Dooming Light 0.1.0-beta.3

Requires DLUMA. Extract this package to mods/native/global/doom.mode, enable
and configure Dooming Light in Mods, then restart Player. Your own Doom,
Ultimate Doom or Doom II IWAD is preferred. Use Freedoom fallback, below the
WAD paths in Game and WADs, is enabled by default and uses the included
Freedoom assets when your selected retail WAD is unavailable. This is logged
as an error. Game, WAD and fallback changes apply on the next map.
Game also offers Freedoom: Phase 1 and Phase 2 directly, independent of
retail discovery and the fallback toggle.

Music defaults to the included GPL-licensed TimGM6mb SoundFont. Leave
SoundFont file empty to use it, or choose your own SF2 file. Classic OPL
remains available. Existing music settings are preserved when updating.

This beta supports single-player Player maps on the compatible x64 Player
build listed in the included source README. Keyboard, mouse and XInput controller
combat are supported. Right trigger fires; D-pad Left/Right cycle weapons.
Movement retains Dying Light parkour. Full Doom movement remains in development.
Disable other combat or HUD replacements when using Dooming Light.

To uninstall, disable the mod, restart Player, and remove the doom.mode folder.
The package contains no retail Doom game data. Freedoom 0.13.0 Phase 1/2,
its BSD license and credits are included, along with the mod's source.
